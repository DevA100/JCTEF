## Setting up the email service (Brevo)

The contact form and the newsletter can't send anything until this is done. It's a one-time setup, and the full step-by-step guide is in the website's README file.

1. **Create a Brevo account** at brevo.com using **info@jctef.org**, so the team can always recover it.
2. **Verify the jctef.org domain** in Brevo. Brevo gives you a few settings to add wherever jctef.org is registered. Whoever manages the domain will need to do this.
3. **Add a sender address**, such as website@jctef.org. Emails from the contact form will come from this address.
4. **Create a mailing list** for the newsletter and note its ID number.
5. **Create a confirmation email template**: the email new subscribers receive to confirm their address. Note its ID number.
6. **Generate an API key**, a password that lets the website use Brevo. Send it to the web team **privately**, not by email or in a group chat, together with the two ID numbers.

Once we have these, we'll connect them and test both forms before launch.
